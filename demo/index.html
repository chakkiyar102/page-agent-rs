An agent that lives in your page.

Alibaba’s page-agent, rebuilt in Rust and compiled to WebAssembly.

It reads the page as indexed text, asks a model for one action, and carries it out with real DOM events. No extension, no headless browser, no screenshots.

Connect a model

Any OpenAI-compatible API works. The key stays in this tab’s memory.

What the model sees.

Each step, the page is flattened to this. Elements you can click or type into get an index. A star marks the ones that appeared since the last step.

One step, four moves.

The same loop page-agent runs, with the same system prompt.

  1. 01

    Observe

    Walk the DOM. Keep what is visible and on top, and number everything you can click or type into.

    [4]<div role=radio aria-checked=false>Pro />
  2. 02

    Think

    Send the text view and the step history to the model, which has to answer with exactly one tool call.

    AgentOutput { evaluation_previous_goal, memory, next_goal, action }
  3. 03

    Act

    Fire pointer and mouse events, or set values through the native setter so React and Vue notice.

    click_element_by_index { "index": 4 }
  4. 04

    Repeat

    Loop until the model calls done. It stops at 40 steps if it never does.

    done { "text": "…", "success": true }

Drop it into any page.

Build once, serve the files in pkg/, and point it at a model. The console is optional. execute() works on its own and resolves with the answer.

The API key lives in the browser. For anything public, put a proxy in front of the model, as you would with upstream page-agent.

The nine tools
click_element_by_indexClick an indexed element
input_textClick, then type into an input, textarea or contenteditable
select_dropdown_optionPick a <select> option by its text
scroll · scroll_horizontallyScroll the page, or the nearest scrollable container
waitWait 1–10 seconds for the page to settle
ask_userAsk you a question mid-task
execute_javascriptRun a script on the page — off unless you opt in
doneFinish and report back
